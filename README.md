# 🍻 Будьмо! (Cheers / Budmo)

**«Будьмо!»** — український сервіс для швидкого й безпечного пошуку компанії на вечір поруч:
у крафтових пабах, барах і затишних кав'ярнях, за улюбленими напоями та спільними інтересами.
Ідея проста: замість нескінченного свайпінгу й переписок — реальні люди поруч і реальні плани «тут і зараз».

Цей репозиторій — загальний опис проєкту. Сам проєкт складається з трьох частин:

| Що це | Стек |
|-------|------|
| Застосунок «Будьмо!» (web-версія + конфігурація мобільних збірок) | React Native, Vite, TypeScript, Tailwind CSS 4, Firebase, Leaflet |
| Промо-лендінг застосунку | React 19, Vite, TypeScript, Tailwind CSS 4, Motion |
| Telegram-бот і HTTP API для звернень до розробників | Rust 2024, teloxide, axum, tokio |

## 📱 Застосунок — `cheers`

Основний продукт. Написаний на React Native + Vite і відображається як мобільний застосунок
(рамка iPhone / Android або адаптивний режим). Для публікації в App Store та Google Play
підготовлено конфігурацію Expo/EAS і Fastlane.

### Можливості

- **Discover** — стрічка людей поруч, які шукають компанію, з фільтрами за напоями та інтересами.
- **Мапа та Радар** — заклади й компанії поблизу на інтерактивній мапі (Leaflet / Google Maps),
  вибір точки на мапі, геолокація в реальному часі.
- **Hangouts** — «клич» на зустріч, заплановані групові зустрічі (місце, час, запрошення людей, календар).
- **Друзі** — додавання в друзі, список друзів, улюблені заклади.
- **Чати** — особисті та групові чати, голосові повідомлення, шифрування повідомлень (AES-GCM через Web Crypto).
- **Профіль** — аватар, інтереси, статистика активності (графіки Recharts), режим енергозбереження.
- **Гейміфікація** — рівні, досвід (XP) за чек-іни в закладах, досягнення.
- **Безпека** — швидкі скарги, блокування користувачів, SOS-кнопка, модерація контенту,
  перевірка віку, гео-блокування території РФ.
- **Сповіщення** — push-сповіщення та центр сповіщень.
- **Мови** — українська, англійська, польська, німецька.
- **Аналітика** — Google Analytics (GA4).
